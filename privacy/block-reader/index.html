块朗读 · 隐私政策

适用于 Chrome 扩展「块朗读 · Block Reader」　·　最后更新：2026-10-28

块朗读（Block Reader，以下简称"本扩展"）的隐私原则很简单： 不收集、不上传、不建账号。你的阅读内容只在你自己的浏览器里处理。

我们收集什么

不收集任何个人身份信息。 本扩展没有账号系统、没有统计埋点、没有广告、没有第三方分析 SDK。 开发者不运营任何接收用户数据的服务器。

网页内容如何处理

  • 当你框选一个区块时，扩展读取该区块的文字，仅用于在本地生成朗读内容与高亮。
  • 这些文字不会被发送给开发者，也不会被保存到磁盘。
  • 页面关闭或点关闭按钮后，提取的文本随之丢弃。

语音合成

朗读采用浏览器自带的语音合成（Web Speech API），分两种情况：

使用的音色 文字去向
本机语音（如 Windows 的 Microsoft Huihui） 文字不离开你的设备
在线语音（如 Google 普通话、Google US English） 文字由 Chrome 浏览器发送给该语音服务的提供方（Google）完成合成

在线语音的数据处理受 Google 的隐私政策约束，与本扩展无关。 开发者既不接收也无法访问这些请求。 如果你不希望文字离开设备，请在播放器的「音色」中选择本机语音，或断网使用 （此时会自动回退到本机语音）。

可选的云音色（自带 Key）

设置页的「云音色」可以在 关闭 / Azure / MiniMax 之间三选一。 只有你主动选择某一家、并填入自己的 Key 之后，文字才会发送给该服务商； 保持「关闭」时，扩展完全不会访问这些接口。

服务商发送的内容数据去向
Azure 语音（Microsoft）待朗读的文本片段Microsoft Azure 语音合成接口
MiniMax 语音（稀宇科技）待朗读的文本片段MiniMax 语音合成接口

Key 只保存在本机 chrome.storage.local，不参与 Chrome 账号同步，也不会发送给开发者。

可选的 AI 润色（DeepSeek）

开启「AI 润色」并填入你自己的 DeepSeek API Key 后， 被你选中区块里的句子会先发送给 DeepSeek：把数字、日期改写成口语，并标注每句的情绪。

  • 只发送选中区块的句子文本，不发送网址、页面标题、浏览记录或账号信息。
  • Key 只存本机，不参与同步，开发者无法访问。
  • 不开启该选项时，扩展完全不会访问 DeepSeek。

设置数据

本扩展使用 chrome.storage.sync 保存你的偏好设置：语速、音色、是否自动滚动、高亮方式、云音色选择。 这些设置由 Chrome 同步到你的 Google 账号，内容中不包含任何网页文字。 各家的 API Key 存在本机 chrome.storage.local，不参与同步。卸载扩展即删除。

权限说明

权限用途
activeTab只有你点击扩展图标、右键菜单或按快捷键时，才允许访问当前标签页
scripting在你触发后，把朗读脚本注入当前页面
storage保存语速、音色等偏好
contextMenus提供右键菜单入口「朗读所选内容」
downloads仅在点击「导出音频」时，把合成好的 WAV 保存到你选择的本地位置
https://*.tts.speech.microsoft.com/仅在选用 Azure 音色时，发送待合成的文字
https://api.minimax.chat/、https://api.minimaxi.com/仅在选用 MiniMax 音色时，发送待合成的文字
https://api.deepseek.com/仅在开启 AI 润色时，发送待改写的句子

这些站点权限只用于调用对应的合成 / 改写接口，不会用来读取这些网站上的内容。 本扩展不申请 <all_urls>，也不会在后台常驻读取你浏览的网页。

数据出售与转让

不存在的。我们不收集数据，因此没有可出售或转让的数据。

儿童隐私

本扩展不收集任何个人信息，适用于所有年龄段。
