旁记 SideNote · 隐私政策

适用于 Chrome 扩展「旁记 SideNote」　·　最后更新：2026-11-03

旁记把视频自带的字幕变成一份可检索的双语文字稿。 它没有服务器、没有账号、没有统计，所有数据都留在你自己的电脑上； 唯一会离开本机的，是你主动配置翻译服务后发送的字幕原文。

我们收集什么

什么都不收集。没有账号体系、没有埋点、没有崩溃上报、没有广告。

开发者不接收、不存储、也无法访问你的任何浏览内容。 扩展的全部代码都打包在安装包里，不加载任何远程脚本。

数据如何被使用

  • 字幕文本：扩展读取当前视频页面的字幕文件（B 站的公开接口， 或页面里已有的 <track>）。这些文本只用于在你的浏览器里 排成文稿、以及（在你配置了翻译服务时）发送给该服务翻译。
  • 音频与画面：不读取。本版本不做语音识别、不录屏、不录音， 也不向任何服务发送音视频流。
  • 本地存储：只保存你的设置（API Key、字号、显示方式等）， 存在 chrome.storage.local，不参与浏览器账号同步。
  • 导出文件：由你自己的浏览器生成并保存到你选择的位置，不经过开发者。

第三方服务

只有在你主动填写 API Key 并开启翻译时，才会发生下面这一次数据外发：

服务收到什么什么时候
DeepSeek 待翻译的字幕原句（纯文本） 抽屉打开且视频有字幕时；连续浏览时按批发送
哔哩哔哩 无（只是读取页面已有的公开接口） 打开 B 站视频页并点击扩展图标时

DeepSeek 如何处理这些文本，适用其自己的隐私政策。如果你不希望任何文本外发， 不要填写 API Key——此时扩展只在本机整理原文，不联网。

权限说明

权限用途
activeTab 只在你点击扩展图标或按快捷键之后，才获得当前标签页的临时访问权， 用于读取该页字幕、显示文稿抽屉。不点击就不生效。
scripting 用户触发后，向当前页面注入文稿抽屉的脚本（不常驻、不后台运行）。
storage 保存字号、显示方式、API Key 等设置。
https://api.deepseek.com/ 仅在用户配置并启用翻译时，向 DeepSeek 发送待翻译的字幕原句。
https://*.hdslb.com/ 读取 B 站的字幕文件（字幕 JSON 托管在这个域名下）。

扩展不申请 <all_urls>，不使用常驻内容脚本， 也不加载远程代码。

儿童隐私

本扩展不面向 13 岁以下儿童，也不收集任何年龄信息。

政策变更

本政策如有变更，会更新本页顶部的「最后更新」日期。 涉及数据外发范围的变更会在扩展的更新说明里单独提示。
